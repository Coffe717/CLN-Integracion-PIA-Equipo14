CargoBox - Sistema de Gestión y Logística

Proyecto Integrador de Aprendizaje (PIA) desarrollado para la gestión de órdenes, control de dominios y pruebas automatizadas bajo un entorno totalmente contenedorizado.

Tecnologías Utilizadas
* **Python 3.13**
* **Pytest & Pytest-cov** (Pruebas unitarias y de cobertura)
* **Docker & Docker Compose** (Contenedorización de servicios)
* **PostgreSQL** (Base de datos relacional)
